| Поле | Назначение |
|---|---|
| `id` | Уникальный идентификатор |
| `phase` | `ToCity`, `FromCity` или `Any` |
| `trips` | Номера рейсов: `1,2,3` |
| `tag` | Тип угрозы для мета-улучшений |
| `weight` | Частота появления |
| `event_text` | Текст ситуации |
| `left_text` | Левое решение |
| `left_result` | Короткий результат |
| `left_tempo` | Изменение темпа |
| `left_engine` | Изменение температуры двигателя |
| `left_visibility` | Изменение видимости |
| `left_load` | Изменение нагрузки |
| `right_text` | Правое решение |
| `right_result` | Короткий результат |
| `right_tempo` | Изменение темпа |
| `right_engine` | Изменение двигателя |
| `right_visibility` | Изменение видимости |
| `right_load` | Изменение нагрузки |
